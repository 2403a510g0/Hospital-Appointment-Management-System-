&#x20;🏥🏥Hospital Appointment Management System



A simple Hospital Appointment Management System developed using Git and GitHub.



\## Modules



1\. Patient Registration

2\. Doctor Management

3\. Appointment Scheduling

4\. Appointment History



\## Technologies Used



\- Python

\- Git

\- GitHub



\## Git Collaboration



The project uses feature branches for parallel development.

Each developer works on a separate feature branch and changes are merged into the master branch.🏥
